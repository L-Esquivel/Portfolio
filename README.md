# Luis Esquivel - Professional Portfolio

*[Leer en Español](#español)*

Professional portfolio built with React and Vite. Designed to showcase Full-Stack and DevSecOps projects, with a focus on premium aesthetics, dark mode, and glassmorphism.

## Features
- **Modern Stack**: React, Vite, Pure CSS (No heavy CSS frameworks).
- **Internationalization (i18n)**: Seamless English/Spanish toggle.
- **Premium Design**: Dark mode by default, glassmorphism UI components, and fluid responsive layouts.

## Running Locally

1. Clone the repository
2. Install dependencies: `npm install`
3. Run the development server: `npm run dev`
